# Known limits in 2.3.1

## Resolved regressions

The five historical v2.0 tests now pass. The checker catches the missing Here contraction, pending markers inside protected syntax, and unclosed YAML/display-math regions. It also reports incomplete fences/inline syntax, distinguishes mandatory fixes from review candidates, and makes incomplete parsing exit nonzero. The original regression test is retained unchanged.

## Still not established

- Independent model quality and author preference have not been evaluated. The 24-case bank contains synthetic examples, not model outputs. The earlier 40 behavior and 20 Word scenarios remain unexecuted independent trials.
- Live Claude Code/Codex discovery, desktop update behavior and native Word repair are not verified here. Refreshing a marketplace is not proof that an installed cache changed.
- Lexical revision checks miss semantic changes, including reordered citation attachment and some fluent paraphrases. No-flags is not semantic equivalence. Thai checks cover selected expressions, not a complete linguistic analysis.
- Wording candidates can be legitimate. Technical terms, genuine comparisons, real triads, deliberate repetition and exact quotations require context. This is not an AI detector.
- Figure manifests, hashes and reviewer-name fields do not prove authenticity, consent, source support, numerical recomputation or visual quality. The CSV checker reads only declared numeric columns. Other data formats and research-generated model imagery require manual review.
- DOCX preflight does not render pages or resolve the full style cascade. Word-first safeguards remain mandatory for existing Word manuscripts.

## Release status

Preview remains intentional. Software regressions and documentation gaps can be fixed without pretending that external evaluation has been completed. See the repository verification record in the repository docs and the evaluation protocol. Never use a green program test to promise acceptance, authorship, zero errors or GitHub stars.

## Full-paper integration limits

ARS handoff and stage propagation are prompt-level instructions, not runtime enforcement. Live paired runs, checkpoint preservation and private-memory behavior have not been measured in either host. A missing dependency blocks ARS mode. The standalone route must be named explicitly. Aboudjem is an inspected optional reference, not an installed dependency.

The full-paper record auditor checks assertions and references within a JSON record. It does not verify URLs, read papers, establish metric validity, inspect source-code execution, certify native Word pages or judge authorship. Even a consistent record leaves submission approval false. Record evidence can itself be incorrect and needs researcher review.

## Punctuation review limits in 2.3.1

The text checker uses approximate sentence boundaries and selected recognized syntax. New punctuation warnings require manual adjudication and never rewrite an input. Thresholds are not grammar rules. Unrecognized technical notation, quotations, citation formats, complex Markdown and Thai sentence boundaries can still produce missed or unnecessary flags. No-flags does not certify grammar, authorship or scientific fidelity. Use the bilingual punctuation guide and source comparison before marking review complete.
