# Manuscript QA record

This is an unfilled template. All checks start as not checked. Mark a check passed only with evidence from the actual artifact and version.

แบบบันทึกนี้ยังไม่ได้ตรวจงานจริง ห้ามตีความช่องว่างว่าเป็นรายการผ่าน

## Artifact identity

Record the manuscript path, version or hash, data snapshot, code revision, result snapshot, template version, review date, and reviewer or tool.

## Layout record

Record the application and version actually used, final DOCX identity, actual Word page count, PDF identity when exported, pages inspected, defects found, fixes applied, and reinspection evidence. For a non-Word workflow, record the actual compiler or renderer and why Word is not applicable.

## Delivery status

Choose working draft, review draft, or submission candidate under R27. List unresolved scientific blockers, unperformed mandatory checks, and author decisions. Do not prefill this status as passed.
