# Original-image request

This is a blank capture checklist, not evidence that a study took place.

Ask for the original files from the actual experiment. Record what the figure must establish, the study/setup version, capture session, viewpoint, scale calibration when relevant, permission and privacy restrictions. Ask which frames represent the stated conditions. Keep full-resolution originals and record any crop or annotation separately. Never ask for identifiable participant images when an apparatus-only view is sufficient.

รายการขอภาพจริงต้องระบุสิ่งที่ภาพต้องแสดง รุ่นชุดทดลอง ช่วงเก็บ มุมภาพ การเทียบมาตราส่วนเมื่อเกี่ยวข้อง สิทธิและความเป็นส่วนตัว ขอไฟล์จากการทดลองจริง ไม่ขอข้อมูลระบุตัวบุคคลเกินจำเป็น เก็บต้นฉบับเต็มและการตัดภาพแยกกัน หากไม่มีภาพ ให้ผู้วิจัยตัดสินใจเก็บใหม่ ตัดสิ่งที่ไม่จำเป็น หรืออนุมัติภาพอธิบายที่ระบุชัด ห้ามให้ AI สร้างภาพคล้ายกันมาแทน

Status starts as Not checked. Receiving a file is not the same as verifying its relationship to the study.
