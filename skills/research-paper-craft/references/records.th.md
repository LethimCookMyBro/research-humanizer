# รูปแบบบันทึกการทำงาน

อ่านเมื่อทำงานส่วนนี้ กฎหลักใน SKILL.md ยังมีผลตลอดงาน

## R29 ใช้แบบบันทึกที่ตรวจได้

รายการต่อไปนี้เป็นช่องข้อมูลสำหรับทำงาน ไม่ใช่ผลวิจัยที่กรอกแล้ว ใช้รูปแบบกระชับที่เหมาะกับโครงการ จะเป็น CSV, JSON, YAML, ตารางคำนวณ หรือบันทึกที่จัดโครงสร้างก็ได้ หากตรวจแต่ละช่องได้

| บันทึก | ช่องที่ต้องมี |
| --- | --- |
| โจทย์งาน | รูปแบบงาน คำถามวิจัย ประเภทบทความ แหล่งตีพิมพ์ ภาษา แม่แบบ ข้อจำกัด การปกปิดชื่อ แหล่งหลัก ผลงานที่ต้องส่ง สิ่งที่ยังต้องตัดสินใจ |
| ทะเบียนแหล่งข้อมูล | รหัส ตำแหน่งหรือ URL ประเภท เวอร์ชันหรือค่าตรวจเอกลักษณ์ หน้าที่ ตำแหน่งที่ตรวจ วันที่เข้าถึงเมื่อเกี่ยวข้อง สถานะ |
| ทะเบียนข้อกล่าวอ้าง | รหัส ข้อความ ประเภทหลักฐาน รหัสแหล่ง ตำแหน่งเฉพาะ ขอบเขต หลักฐานที่ขัด สถานะการตรวจ ตำแหน่งใช้ในบทความ |
| ทะเบียนตัวเลข | รหัส ปริมาณ ค่าดิบ ค่าที่แสดง หน่วย ประเภทหลักฐาน แหล่งดิบ แหล่งผลที่กำหนด รหัสค่าตั้งหรือรัน สูตร ตัวกรอง ตัวหาร วิธีรวมข้อมูล การปัดเศษ สถานะ ตำแหน่งใช้ |
| ทะเบียนสัญกรณ์ | สัญลักษณ์ ชื่อ นิยาม โดเมน รูปร่าง หน่วย ตำแหน่งแรก ส่วนโค้ดที่ตรงกัน |
| ทะเบียนภาพ | รหัส หน้าที่ทางวิชาการ ประเภทภาพ แหล่ง เกณฑ์เลือก การแปลง การแทนค่า คำบรรยาย ต้นฉบับแก้ได้ ไฟล์ส่ง สิทธิ ผลตรวจตัวตน ผลตรวจขนาดจริง |
| บันทึกอ้างอิง | รหัส ข้อมูลบรรณานุกรมที่ตรวจแล้ว รหัสแหล่ง เวอร์ชัน ข้อความที่อ่าน ข้อที่รองรับ ข้อจำกัดการเข้าถึง สถานะการแก้ไขเมื่อเกี่ยวข้อง |
| รายงานตรวจ | รหัสตรวจ ไฟล์และเวอร์ชัน ขั้นตอนที่ทำ ตำแหน่งหลักฐาน สถานะ ปัญหา การแก้ ผู้ตรวจหรือเครื่องมือ วันที่ |
| บันทึกตัดสินใจ | ปัญหา ทางเลือก หลักฐาน ข้อตัดสิน ผู้ตัดสิน ไฟล์ที่ได้รับผล เรื่องที่ยังพึ่งข้อมูลอื่น |
| ทะเบียนข้อมูลที่ต้องขอผู้วิจัย | รหัสคำขอ สิ่งที่ขาด ส่วนหรือภาพที่ใช้ เหตุผลที่ต้องใช้ แหล่งที่ตรวจแล้ว คำถามที่ส่ง คำตอบผู้วิจัย แหล่งที่ได้รับหรือทางเลือกที่อนุมัติ ประเภทหลักฐาน สิ่งที่ยังต้องรอ สถานะ |
