# Research Humanizer v2.3.4 local upgrade

## สถานะการเตรียมเผยแพร่

ผู้ดูแลอนุญาตให้เผยแพร่ชุดตรวจทานนี้แล้วเมื่อ 24 พฤศจิกายน 2026 การเผยแพร่ใช้ workflow เดิมโดยรันชุดทดสอบก่อนสร้าง Release ส่วนบันทึกด้านล่างอธิบายสถานะ ณ วันเตรียม candidate ไม่ใช่สถานะล่าสุดของ GitHub

## สถานะเดิมเมื่อเตรียม candidate

เตรียมเป็นชุดตรวจทานในเครื่อง ยังไม่ push สร้าง tag หรือ Release และไม่ deploy เว็บไซต์ เวอร์ชันที่ตรวจพบใน main ยังเป็น v2.3.3 ที่ commit 664cf952cfa6854ccf4fcc67145e4b9492226207

คำสั่งหลักและ plugin ยังชื่อเดิม เพิ่มความสามารถใน research-paper-craft ไม่ได้สร้าง skill ใหม่

## สิ่งที่ใช้เป็นต้นทาง

ใช้ไฟล์ Pasted text.txt ที่ผู้ใช้แนบครบทั้ง 72 ข้อ และชุดแก้ไขบทเปิดกับความกระชับที่แนบก่อนหน้า แหล่งแรกระบุเองว่าเป็นบทเรียนสังเคราะห์ ไม่ใช่บทถอดคำอาจารย์ทุกข้อ จึงไม่นำข้อเสนอทั้งหมดไปประกาศเป็นหลักวิจัยสากล

ไม่ได้เปิดหรืออ้างว่าตรวจไฟล์ส่วนตัวที่ลิงก์ในคู่มือนั้น ไม่มีเอกสารผู้เข้าร่วม ภาพจริง ข้อมูลดิบ หรือ path ภายในของงานเดิมถูกรวมในแพ็กเกจ มีเฉพาะหัวข้อหลักการที่ทำให้ใช้ข้ามโครงการได้

ต้นทางในเครื่องคือ candidate v2.3.3 ที่แนบในแชต ปรับชื่อ README ของ skill ให้ตรงฉบับเผยแพร่แล้วตรวจ Git tree พบว่า skills, commands, tests, evals และ workflow ตรงกับ commit บน GitHub ทุก byte ก่อนเริ่มแก้ เอกสารระดับ root ที่ไม่ได้ตรวจทีละไฟล์ไม่อ้างว่าเป็น fresh checkout ทั้ง repository และไม่ส่งทับออนไลน์

## บันทึกและการเชื่อม ARS

ใช้บัตรงาน Decision log ทะเบียนต้นทางและตัวเลข Paper Map Metric Plan Figure Register และ QA Report เดิม เพิ่มช่องเลือกใช้ใน project brief และ checklist ใน QA โดยไม่เปลี่ยน CSV header หรือ full-paper-run schema

ส่งบริบทผ่าน handoff เดิม ให้ ARS เป็นเจ้าของ workflow และจุดยืนยัน งาน revise ไม่เปลี่ยนวิธีหรือข้อสรุปทางวิทยาศาสตร์โดยไม่มีอนุมัติ การเขียนใหม่ยังใช้ Humanizer ตั้งแต่ร่างแรก

## ความเข้ากันได้และความลับ

สคริปต์ใช้งานจริงทั้งห้าตัวไม่เปลี่ยน กฎเดิม R00 ถึง R50 ทั้งสองภาษาและไฟล์ Humanizer ต้นฉบับถูกตรวจเทียบด้วย hash รายข้อ ไม่มีการลดกฎเก่าเพื่อให้การทดสอบผ่าน

ตาราง provenance/safeguards-map.v2.3.4.json เชื่อมทุกข้อ 1 ถึง 72 กับกฎเดิมและส่วนเสริม ระบุขอบเขตและวิธีปรับใช้ การมีแถวครบหมายถึงครอบคลุมคำสั่ง ไม่ใช่พิสูจน์ว่า AI ทำตามจริงหรือปิด Gap ทางวิทยาศาสตร์แล้ว

## ข้อจำกัด

ตัวตรวจเดิมไม่ได้เพิ่มความสามารถอ่านข้อความรอยแก้ วิเคราะห์ log ตรวจจริยธรรม หรือดาวน์โหลดกลับจาก Drive อัตโนมัติ สิ่งใหม่คือขั้นตอนคำสั่งและรายการตรวจที่ต้องใช้แหล่งกับเครื่องมือจริง

สถานการณ์กดดัน 25 กรณีเป็นข้อมูลสังเคราะห์สำหรับประเมินต่อ ยังไม่ได้รันโมเดลอิสระหรือ ARS จริง ไม่ได้เปิด Word หรือซ่อม paper ของผู้ใช้ในรอบนี้ ผลทดสอบซอฟต์แวร์ไม่ยืนยันความถูกต้องทางวิทยาศาสตร์ ความเหมือนคน หรือการรับตีพิมพ์

ก่อนนำขึ้น GitHub ให้เทียบกับ main ปัจจุบันและขออนุมัติการเผยแพร่ เพราะ workflow เดิมจะสร้าง prerelease เมื่อ VERSION เปลี่ยนบน main
