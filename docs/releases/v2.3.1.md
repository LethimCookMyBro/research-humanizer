# Research Humanizer 2.3.1

**Preview release.** A punctuation and sentence-structure patch to 2.3.0. Full-paper drafting, ARS coordination, research evidence, real-image requirements and Word-first safeguards remain.

## Changed

- Add sentence-level review for comma load across soft-wrapped lines. Three or more prose commas trigger review, not a ban or automatic rewrite.
- Review spaced hyphens, symbolic shorthand, slash alternatives, ellipses, repeated punctuation, explanatory parentheses and selected word-fragment chains. Review long and-chains so replacing every comma with and is not treated as a repair.
- Preserve recognized mathematical and numeric forms, lexical compounds, ordinary sentence endings, citations, quoted passages, code, URLs and paths. Fix false required-fix reports in common author-year/Pandoc citations, numeric ratios and timestamps. Fullwidth colon/semicolon variants now follow their existing prose rules.
- Add English and Thai guidance to the core writing route and ARS handoff. Keep source conditions, simultaneity, temporal order and citation attachment after splitting sentences.
- Retain the read-only CLI and its existing API. New heuristic findings have severity review. Existing house-style violations remain required_fix. An incomplete supported parse is still not a pass.

## Verification boundary

Tests use authored synthetic examples. They check detection, protected contexts, CLI exit codes, line locations and input preservation. They do not demonstrate better model prose, complete grammar analysis or a successful real-paper run. Native Word review and live ARS/Claude/Codex integration remain unverified. See docs/VERIFICATION.md for executed results.

Research Humanizer remains MIT. ARS is an external dependency under CC BY-NC 4.0. Historical release assets and the original Humanizer are not rewritten.

## Update

Refresh the installed marketplace and update the plugin through the host, then check the installed version. A GitHub Release does not force a cached Claude installation to update. ZIP imports are snapshots. Existing v2.3.0 users keep the same skill and command names.
