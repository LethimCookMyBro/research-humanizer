# Research Humanizer 2.3.2

**Preview release.** A text-integrity patch to 2.3.1. The full-paper and ARS workflow introduced in 2.3.0 remains unchanged.

## Fixed and extended

- Close the seven missed cases in the retained 28-case v2.3.1 probe report. They cover lowercase text after an unspaced period, multiword fragment candidates, repeated fullwidth stops, replacement characters, a literal square in prose, a zero-width Latin-word interruption and an unmatched double quote.
- Review mixed/small full stops, selected directional/control characters and additional quotation styles. Report source code points and positions for character diagnostics.
- Preserve complete supported quotations across soft wraps. An unmatched quote does not suppress later prose checks or pending-source markers.
- Protect common domains, email addresses, function calls and additional scientific file extensions from the broader dot-spacing check.
- Keep legitimate numbers, equations, abbreviations, short complete sentences, Thai word boundaries and script/emoji joins. New findings are contextual review candidates, not automatic replacements or authorship scores.
- Keep all tools read-only. Preserve the original Humanizer, evidence rules, figure requirements and Word-first safeguards. Update both plugin versions, guides, READMEs and website version references.

## Verification

The original public synthetic probe is retained without changes. New tests cover the seven misses, guard cases, CLI exit codes, byte preservation, source locations and malformed inputs. The exact executed counts and source pins are recorded in docs/VERIFICATION.md and docs/verification/release-v2.3.2.json. The release workflow reruns the full suites before publication.

These tests do not establish universal punctuation coverage, grammar correctness, improved model prose, live ARS interoperability or native Word repair. Unmarked dotted names, unusual quote conventions, multilingual syntax and rendered missing-font boxes still require human review. A literal square is not proof of corrupted content. No script can invent the original missing glyph.

## Updating

The skill remains research-paper-craft and the ARS command remains research-full. Refresh the installed marketplace and update the plugin through the host. A release cannot force a cached Desktop installation to refresh. ZIP imports remain snapshots.
