# Research Humanizer 2.3.0

**Preview release.** Full-paper drafting with research-specific prose, evidence and document safeguards. It is usable independently or as a prompt-level companion to a separately installed ARS workflow.

## Added

- Explicit full-paper, revise and read-only audit modes. Humanize from the first draft rather than treating the whole paper as a final rewrite job.
- Claude Code entry `/research-humanizer:research-full`, which loads our contract and the actual installed ARS pipeline. It preserves upstream researcher confirmations and reports missing dependencies.
- English and Thai guidance for literature search, official venue instructions, representative-paper analysis and metric-to-data planning.
- Per-researcher, project-scoped author context. Available memory can inform prose preferences, never replace result evidence or author approval.
- Blank search, literature, metric and handoff records, plus a read-only full-paper record auditor.
- A documented research adaptation of Aboudjem's humanizer concepts. No generic personality injection, contraction preference, uncertainty deletion or AI-tell score target.

Existing real-image provenance, reproducible graphs, evidence-linked overviews, equation/code correspondence, anonymity and Word-first preservation remain in place. Original manuscript style restrictions are unchanged.

## Dependencies and licenses

Install Academic Research Skills separately to use ARS. The inspected ARS source is CC BY-NC 4.0 and is not copied into or relicensed by this MIT package. Aboudjem Humanizer is an inspected design reference, not a required extra installation. Its MIT notice is included alongside the original Humanizer attribution.

## Verification boundary

The local test results and source pins are in `docs/VERIFICATION.md`. Release automation reruns the repository, skill and historical-regression suites before publishing. These are software and static-contract tests, not evidence that a model obeys every rule or that a scientific paper is correct.

Live full-pipeline runs in Claude Code or Codex, native Word review and independent writing-quality evaluation have not been demonstrated for this adapter. No paper, real study image or model-quality score is fabricated for the release.

## Updating

A GitHub Release provides a tagged download. It does not force Claude Desktop or Codex to refresh their installed plugin cache. Refresh the configured marketplace and update the plugin through the host, then check the installed version. ZIP imports are snapshots. Back up any local customizations outside the plugin before replacing a snapshot.
