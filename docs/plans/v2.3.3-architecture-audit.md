## Design choices

Add one bilingual reference module. Keep old numbered rule bodies unchanged. Put cross-links before existing rule blocks so archived fingerprints retain their meaning. Add optional fields through guidance and the QA/handoff templates; do not migrate existing CSV headers or create a competing claim ledger. Keep source classification, support judgment and execution status separate.

The optional machine audit checks declarations and references only. It does not retrieve studies, recalculate results, judge actual prose semantics, prove novelty or promote an expert's opinion into a universal rule. Scientific review remains an evidence-reading procedure performed by the agent and researcher.
